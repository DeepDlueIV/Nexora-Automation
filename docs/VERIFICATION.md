# Проверка Nexora Automation

Дата: 19 октября 2026 года, Asia/Novosibirsk.

## Сборка и браузеры

| Проверка | Результат |
|---|---|
| `npm run build` | Успешно: TypeScript и production-сборка Vite 8.3.4 |
| `npm run test:e2e -- --workers=2` | **12 passed**: шесть сценариев в Chromium и шесть в Firefox |
| Рабочие npm-зависимости | `npm audit --omit=dev --audit-level=high`: **0 vulnerabilities** на момент проверки |
| Google Fonts | Instrument Serif regular/italic и Inter 400/500/600 загрузились в обоих браузерах |
| Видеофон | Оба браузера загрузили и декодировали исходный MP4; `readyState=4`, muted/autoplay/loop настроены |
| Ошибки JavaScript | Не обнаружены при визуальной проверке страницы и открытии тура |
| Desktop | Документ и viewport: 1440 × 900, высота строки заголовка 76px |
| Mobile | Документ и viewport: 390 × 844, весь dashboard помещается по ширине |

Проверенные размеры: **1440 × 900, 1366 × 768, 1024 × 768, 768 × 1024, 390 × 844, 320 × 568, 844 × 390**. Автоматические сценарии проверили отсутствие прокрутки документа, видимость основных CTA, круглую кнопку Play, данные dashboard, переходы по туру, диалоги, удержание и возврат клавиатурного фокуса, reduced motion и доступность локального постера.

Браузерные тесты работают с заблокированными внешними ресурсами: это проверяет пригодность локального постера и резервных шрифтов. Отдельная визуальная проверка использовала настоящий видеофон и Google Fonts. Снимки сделаны с готовой production-сборки, без изменения верстки для скриншотов. Для снимка видеокадр остановлен на первой секунде после проверки загрузки; исходный сайт продолжает использовать autoplay/loop.

## Локальный лаунчер

Проверка выполнена на Linux с Node.js 24.19.0 в отдельной копии реального проекта, **в папке с пробелами в пути**.

| Сценарий | Наблюдаемый результат |
|---|---|
| Первый запуск | Реальный `npm ci` установил 136 пакетов, production-сборка прошла, HTTP 200 на `127.0.0.1:46335` |
| Повторный запуск | Установленные зависимости проверены и использованы повторно; файл состояния установки не перезаписан |
| Занятый порт | Предпочтительный порт 37339 был занят; сайт запустился на 37340, исходный сервер продолжил работать |
| Область доступа | Сервер слушает только IPv4 loopback `127.0.0.1` |
| Остановка | `Ctrl+C` завершил лаунчер с кодом 0 и закрыл его слушающий сокет |
| Синтаксис | `node --check scripts/start-local.mjs` и `bash -n start-website.sh` прошли |
| Ошибочные параметры | Неподдерживаемый аргумент и некорректный порт завершились с понятной ошибкой и ненулевым кодом |

Windows-файлы `START-WEBSITE.cmd` и `scripts/start-local.ps1` прошли отдельный анализ кода, включая PowerShell 5.1, пути с пробелами, выбор архитектуры, проверку SHA256 и повторное использование переносимого Node.js. **Непосредственный запуск CMD/PowerShell на Windows в этой среде не выполнялся.** Автоматическое открытие системного браузера также не запускалось в smoke-сценариях: использовался `--no-open`, а страница отдельно открывалась в тестовых Chromium и Firefox.

## Границы проверки

Лендинг и декоративный dashboard не подключены к AI API, банковским счетам или серверу отправки заявок. Календарь и почта подключаются через значения, описанные в README. Сами внешние сервисы бронирования и электронной почты не проверялись, поскольку их адреса не предоставлены.
